# Developer Tools

This project focuses on learning how to use browser Developer Tools to inspect, debug, and modify web pages.

## Task 0: Responsive Device
Used Chrome DevTools Device Toolbar to view the website using the iPhone X device.

## Task 1: Change the Background Color
Changed the body background color to #4233bd using Chrome DevTools.

## Task 2: Force Element State
Used Chrome DevTools to force the hover state of the cake block in the Portfolio section.
